# ASCENDRA

> **Where Intelligence Meets Ambition.**

ASCENDRA is an AI-powered learning and career platform designed to empower students to learn, practice, code, prepare for technical & HR placement interviews, and track their progress through a modern AI-first experience.

---

## Key Modules & Features

- **Authentication & Face Verification**: Secure email and face-recognition enrollment & login powered by client-side biometrics.
- **Learning Workspace**: Structured subject, chapter, and lesson pathways with interactive progress sync.
- **Practice Hub**: Topic-based diagnostic practice sets with instant evaluation metrics.
- **Quiz Engine**: Adaptive diagnostic quiz assessments with scorecards.
- **CodeLab Workspace**: Online coding workspace supporting Python, Java, JavaScript, and C++ with test case execution and simulated AI code reviews.
- **AI Interview Studio**: Placement interview rounds (HR, Behavioral, Technical, AI Engineer, Frontend, Backend, Full Stack) with live webcam gaze-stability proctoring and evaluation reports.
- **Insights & Profile**: Centralized command center tracking streaks, completed milestones, and unlocked achievements.

---

## Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Lucide React, Framer Motion
- **Biometric Proctoring**: Face-API.js (Client-side face detection & descriptor matching)
- **Code Editor**: Monaco Editor (`@monaco-editor/react`)
- **State Management**: Zustand (Persisted), React Context API

---

## Quick Start

### Installation & Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Launch development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```
